# Multimodal Emotion Recognition Using Audio CNN, Whisper Transcripts, and Text RNN

---

# 1. Introduction

Emotion recognition is an important task in artificial intelligence and human-computer interaction. In this project, I worked on recognizing human emotions using two different modalities: audio and text. The audio features were extracted from speech signals, while the text data was generated using OpenAI Whisper transcription.

The main objective of this project was to compare the performance of audio-only, text-only, and multimodal emotion recognition systems using deep learning techniques.

---

# 2. Objective

The objectives of this project were:

- To build an Audio CNN model for speech emotion recognition
- To generate transcripts using Whisper
- To build a Text RNN/LSTM model for text-based emotion recognition
- To combine both modalities using Late Fusion techniques
- To compare the performance of all models

---

# 3. Dataset Used

The RAVDESS dataset was used for this project. It contains emotional speech recordings from multiple speakers with different emotion classes such as:

- Neutral
- Calm
- Happy
- Sad
- Angry
- Fearful
- Disgust
- Surprised

The dataset contains labeled audio samples which were later converted into spectrograms for training the CNN model.

---

# 4. Audio-Based Emotion Recognition

For audio emotion recognition, Mel Spectrogram features were extracted using Librosa. These spectrograms were then used as input to a Convolutional Neural Network (CNN).

## Steps Performed

- Audio loading using Librosa
- Mel Spectrogram extraction
- Normalization
- CNN model training
- Accuracy and loss visualization

## Audio CNN Architecture

- Conv2D layers
- Batch Normalization
- MaxPooling
- Dropout
- Dense layers with Softmax output

![Architecture Diagram](architecture_results_diagram.png)

---

# 5. Text-Based Emotion Recognition

The audio samples were transcribed into text using OpenAI Whisper. These transcripts were then processed using NLP techniques.

## Steps Performed

- Whisper transcription
- Tokenization
- Padding sequences
- Label encoding
- LSTM model training

The text model was trained using tokenized transcript sequences.

---

# 6. Multimodal Fusion

Late Fusion techniques were used to combine predictions from both Audio CNN and Text LSTM models.

The following fusion methods were implemented:

- Average Fusion
- Weighted Fusion
- Maximum Confidence Rule

Weighted Fusion gave higher importance to the audio model because the audio modality performed better than the text modality.

# 10. Challenges Faced

While working on this project, I faced several practical issues:

- Kernel crashes during model training
- Variable mismatch errors after restarting Jupyter Notebook
- Shape mismatch between audio and text prediction arrays
- Whisper transcripts were sometimes inaccurate
- Training was slow due to CPU limitations
- Maintaining synchronization between both modalities was difficult

These issues helped me understand the importance of preprocessing and debugging in deep learning projects.

# 12. Conclusion

This project helped me understand how multimodal deep learning systems work using both audio and text information. Through this work, I learned feature extraction, CNNs, LSTMs, Whisper transcription, fusion techniques, and model evaluation.

The audio model performed significantly better than the text model because emotional information was more strongly represented in speech signals. However, combining both modalities improved the overall robustness of the system.

Overall, this project gave me practical experience in multimodal emotion recognition and deep learning workflows.
